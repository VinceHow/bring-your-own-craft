# Lamplight comps

High-fidelity mocks of the studio's key moments, in the Lamplight look. Standalone pages (no server state), served at
`/looks/comps/<file>`. Shared: `lamp.css` (tokens, table, paper, marks, motion), `journey.css` (the rough journey).
Fonts: Newsreader + Hanken Grotesk (dealt by taste-skill), local in `../fonts/`.
Each page plays its moment on load; `?still=1` jumps to the end state for screenshots.
